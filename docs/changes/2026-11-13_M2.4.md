# 2026-11-13 · M2.4 — the MIDI type

## What changed

**m5** (`mmmmm`, commit `a7f528e`)
- New [`m5.Midi`](../../../../mmmmm/src/m5/midi.py): tracks of notes, controllers (CC), pitch bends and programs, all
  timed in **ms**, plus the file's tempo/meter `TimeMap`. New dependency: **mido** (small, pure Python).
  - `Midi.from_file` / `to_file`: reads type 0/1/2 (type 0 is split into one track per channel; the tempo-only
    conductor track is dropped; RPN 0 sets the bend range), writes type 1.
  - `to_sequence`: one staff per track, simultaneous notes → chords, instrument = track name (unnamed tracks stay
    unnamed), black keys spelled as sharps; the pitch bend at a note's start → `detuning_cents` (microtones).
  - `from_sequence`: one track per staff; velocity from the notes, else from the **dynamics** (p 49, mf 80, f 96…),
    else 80; microtones → **pitch bends**, with notes spread over channels so differently detuned notes never share one.
    Keeps the Sequence's tempo map (from a score or MIDI file), else 120 BPM 4/4.
  - `lanes()` and `cc_to_bpf(cc | PITCH_BEND, channel, track)`: a controller lane as a step BPF (0–127), or the bend
    lane in cents.
- Fixture `tests/data/duo_cc.mid` (+ `make_midi_fixture.py`), 15 tests in `tests/test_midi.py`.

**com5fy** (this commit)
- Type `M5_MIDI` ([nodes/types.py](../../nodes/types.py)).
- [nodes/io.py](../../nodes/io.py): **Load MIDI** (`.mid` from `input/`), **Save MIDI** (numbered file in `output/`,
  like Save Audio; outputs the path). Category `m5/io`.
- [nodes/convert.py](../../nodes/convert.py): **MIDI to Sequence**, **Sequence to MIDI** (`bend_range` is an
  advanced input), **MIDI to BPF** (lane CC / pitch bend, cc number, channel 1–16 or 0 = any, track or −1 = any).
  Category `m5/convert`.
- Workflow [`workflows/M2.4_midi.json`](../../workflows/M2.4_midi.json) (+ `api/` version, input
  `workflows/inputs/m5_duo_cc.mid`), node tests `tests/test_midi_nodes.py`.

## How to test

1. Restart ComfyUI (Python changed) and make sure mido is installed: `uv pip install -e mmmmm/` from the ComfyUI root.
2. Copy `custom_nodes/com5fy/workflows/inputs/m5_duo_cc.mid` into ComfyUI's `input/` (the workflow runner does this
   for you).
3. Open `custom_nodes/com5fy/workflows/M2.4_midi.json` and press Run. Expect:
   - **Loaded MIDI** (Preview as Text): Clarinet [ch 1] 6 notes, CC1 modulation (9), pitch bend (2); Piano [ch 2]
     12 notes, CC64 sustain (2); 100 BPM, 3/4, 2 tempo/meter changes.
   - **MIDI as a Sequence**: Clarinet and Piano staves; the clarinet's 4th note (A4) with a quarter-tone sharp.
   - **… as a Score**: 3/4 at ♩ = 100, ♩ = 75 at bar 3, 4/4 at bar 4.
   - **CC1 as a BPF**: green step curve 0 → 100 → 20 over 3.6 s.
   - Bottom row: the M2.1 flute/cello score saved as `output/m5/duo_0000N_.mid` (path in Saved MIDI's output);
     open it in a DAW or MuseScore.

## Known limitations

- No MIDI viewer yet (piano roll is M3.4): use Preview as Text, or MIDI to Sequence → Sequence Viewer.
- Bends and CCs **during** a note (glissandi, vibrato) aren't kept on Events, only the bend at the note's start.
- No BPF → CC lane (writing automation into MIDI) yet; planned with M4.6 / M7.
- Velocities aren't turned back into dynamics on MIDI → Sequence → Score.
- Key signatures, lyrics and markers in MIDI files are ignored.
- More detunings sounding at once than the 15 melodic channels: the extra notes take the nearest bend.
