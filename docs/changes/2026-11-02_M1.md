# M1: audio → score with Orchidea (W1), 2026-11-02

## What changed

**Orchidea node (`m5_Orchidea`, [nodes/convert.py](../../nodes/convert.py))**
- **Sound database dropdown (M1.2).** The `db_files` / `sound_paths` text fields are gone. A new `database` dropdown
  lists every `.db` file under ComfyUI's `models/m5/orchidea_db/`, spectrum databases first. That folder is registered
  with `folder_paths` (and created on first start) in the new [nodes/paths.py](../../nodes/paths.py); you can add more
  locations under `orchidea_db` in `extra_model_paths.yaml`. The samples folder is found next to the `.db` file
  (`TinySOL/TinySOL.spectrum.db` → `TinySOL/TinySOL/`).
- **Clear errors (M1.1).** With no database installed, the dropdown shows `(no database found: see tooltip)` and
  running the node explains how to install TinySOL and where to put it. A missing database file or samples folder is
  reported by name before Orchidea runs. Before this change you got Orchidea's own "no connection.txt" error.
- **More inputs (M1.1).** `styles` and `dynamics` filters (blank means no filter), `reverb` on/off for the rendered
  audio. Under *Show advanced inputs*: `onsets_timegate`, `segmentation` (flux / powerflux / frames), `pop_size`, and
  `max_epochs`. The `onsets_threshold` maximum is now 2, so you can set it above 1, which makes the target static.
  TinySOL setup is in the node description and the database tooltip.

**m5 ([mmmmm/src/m5/orchidea.py](https://github.com/dzluke/mmmmm/blob/main/src/m5/orchidea.py))**
- `SoundDatabase(db_file, sound_path)` with `from_db_file()`, `parameters()` and `check()`.
- `orchestrate(audio, parameters, database=None)` checks the database before running.
- **Platform (M1.3).** The bundled binary is universal (arm64 + x86_64), and a test confirms the arm64 slice. From
  native Python it runs as arm64. If Python itself runs under Rosetta, it is started with `arch -arm64`. On any OS
  other than macOS you get a clear error unless `ORCHIDEA_EXECUTABLE` points to your own binary.

**W1 end to end (M1.4)**
- [workflows/api/W1_audio_to_score.json](../../workflows/api/W1_audio_to_score.json) uses the new inputs and must
  fill all four viewers and players. The runner has a new `expect_outputs` check
  ([workflows/run.py](../../workflows/run.py)). The workflow is marked `slow` + `external`.
- New UI workflow [workflows/M1.4_w1_audio_to_score.json](../../workflows/M1.4_w1_audio_to_score.json) with a Note.
- README: an Orchidea setup section.

## How to test

1. Put TinySOL in `models/m5/orchidea_db/` (from the ComfyUI root):
   `ln -s /path/to/TinySOL models/m5/orchidea_db/TinySOL`. The linked folder must hold `TinySOL.spectrum.db` and the
   `TinySOL/` samples folder. On the dev machine this symlink already exists.
2. Restart ComfyUI (Python changed).
3. Open `custom_nodes/com5fy/workflows/M1.4_w1_audio_to_score.json` (drag it onto the canvas) and press Run.
4. Expected (about 1 s on the 1 s 440 Hz sine):
   - The Score Viewer shows a few instruments playing around A4, quantized.
   - The Sequence Viewer shows the same notes at their real onset times.
   - Two players: Orchidea's own rendering (with reverb) and m5's dry mix of the same samples.
5. Try the inputs:
   - a smaller `orchestra` (e.g. `Fl Ob ClBb Vn Vc`)
   - `styles` = `ord`, or `dynamics` = `pp p`
   - `sparsity` 0.1
   - `reverb` off
   - the advanced inputs
6. Check the missing-database message: temporarily move the symlink away, press R, and run.

Headless: `uv run python custom_nodes/com5fy/workflows/run.py --all`. Tests: `cd mmmmm && uv run pytest -m ""` and
`uv run --with pytest pytest custom_nodes/com5fy/tests -m ""`. All pass with the committed `orch_config.txt`.

## Known limitations

- The only shipped test audio is a sine wave (plan §8.4). For musically interesting results, load your own WAV from
  `input/` (a chord, a bell, an orchestral excerpt).
- Saved workflows that use the old `db_files` / `sound_paths` inputs load with shifted widget values. Re-pick the
  database and check the other widgets. No saved UI workflows existed before this one.
- Orchidea settings with no input (hysteresis, partials window, export, …) still come from m5's `orch_config.txt`.
- The tooltip shows the absolute path of `models/m5/orchidea_db` on this machine.
